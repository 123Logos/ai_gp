以下为“AI 智能日程管家”数据库的纯表结构设计文档，可直接复制为 `.md` 文件使用。

## 用户表 (`ai_user`)
（必须，支撑用户系统）

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | bigint(20) | 否 | 自增 | 内部主键 |
| `user_id` | varchar(64) | 否 | - | 用户唯一标识（对外使用，与任务表关联） |
| `username` | varchar(50) | 是 | NULL | 用户名（登录名） |
| `password_hash` | varchar(255) | 是 | NULL | 密码哈希（如需登录） |
| `email` | varchar(100) | 是 | NULL | 邮箱 |
| `phone` | varchar(20) | 是 | NULL | 手机号 |
| `avatar_url` | varchar(255) | 是 | NULL | 头像地址 |
| `create_time` | datetime | 是 | CURRENT_TIMESTAMP | 创建时间 |
| `update_time` | datetime | 是 | CURRENT_TIMESTAMP | 更新时间（随改动自动更新） |

## 核心任务表 (`ai_task`)
（必须，存储待办日程）

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | bigint(20) | 否 | 自增 | 主键ID |
| `user_id` | varchar(64) | 否 | - | 用户ID（关联 `ai_user.user_id`） |
| `content` | varchar(255) | 否 | - | 任务标题/简要内容 |
| `description` | varchar(500) | 是 | NULL | 任务详细描述（如“带笔记本”等备注） |
| `plan_time` | datetime | 否 | - | 计划执行时间 |
| `priority` | tinyint(4) | 是 | 0 | 优先级: 0-普通, 1-紧急 |
| `status` | tinyint(4) | 是 | 0 | 状态: 0-待办, 1-已完成, 2-已取消, 3-已过期 |
| `is_reminded` | tinyint(1) | 是 | 0 | 是否已提醒: 0-否, 1-是 |
| `create_time` | datetime | 是 | CURRENT_TIMESTAMP | 创建时间 |
| `update_time` | datetime | 是 | CURRENT_TIMESTAMP | 更新时间（随改动自动更新） |

## 提醒记录表 (`ai_reminder`)
（可选，用于记录推送历史与问题排查）

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | bigint(20) | 否 | 自增 | 记录ID |
| `task_id` | bigint(20) | 否 | - | 关联的任务ID |
| `user_id` | varchar(64) | 否 | - | 用户ID |
| `remind_time` | datetime | 否 | - | 计划提醒时间（通常等于任务 `plan_time`） |
| `is_sent` | tinyint(1) | 是 | 0 | 是否已推送: 0-未推送, 1-已推送 |
| `sent_time` | datetime | 是 | NULL | 实际推送时间 |
| `create_time` | datetime | 是 | CURRENT_TIMESTAMP | 本记录创建时间 |

### 索引建议
*   `ai_user`: 唯一索引 `uk_user_id` (`user_id`)；普通索引 `idx_username` (`username`)。
*   `ai_task`: 联合索引 `idx_user_time` (`user_id`, `plan_time`)；普通索引 `idx_status` (`status`)。
*   `ai_reminder`: 普通索引 `idx_task_id` (`task_id`)；普通索引 `idx_user_id` (`user_id`)。
